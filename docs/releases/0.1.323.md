# 0.1.323

## 新增功能

- 更新确认页新增“更新日志”，点击版本号打开窗口后，即可在“立即更新”按钮上方查看目标版本的 GitHub Release 说明。
- 长更新日志支持独立滚动，保留原文换行；发布方未填写说明时，显示“该版本暂无更新日志”。

## 问题修复

- 同一版本的发布说明被修改后，再次打开更新入口会重新创建确认页，避免复用旧窗口而显示过时日志。

## 发布流程改进

- 每次准备提交或发布时，由 AI 根据上一个已发布版本以来的实际改动整理中文更新说明，随版本一起保存到仓库。
- CI 在打包前检查当前版本对应的日志文件、版本标题及非空中文变更条目；缺失或不符合要求时停止打包和发布。
- 新建 Release 和同版本重新发布都使用仓库中的说明正文，替代只有 Full Changelog 对比链接的自动说明。

## 使用说明

- 更新日志以纯文本展示；下载安装开始后，窗口继续显示原有步骤进度和结果。
