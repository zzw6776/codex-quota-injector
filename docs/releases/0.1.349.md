# 0.1.349

## 修复

- 当前 Codex 登录会话失效时会先尝试续期；确认无法续期后自动跳过其他失效账号并切换到下一个可用账号，没有可用账号时直接启动 Codex 官方浏览器登录。
- 官方登录完成并确认新凭据落盘后才重新启动 Codex；登录失败或取消时停止恢复，不再因账户加载错误反复重启。
- 注入器冷启动时会先恢复或切换失效账号，自动恢复后的重启还会等待活动回合和任务历史稳定，避免过期 Session 阻断启动或中断进行中的回合。
- 已标记失效的账号不会再被同一份旧凭据重新激活，避免重启后重复进入异常状态。
- macOS 同时打开多个开发版日志窗口时，旧窗口现在会可靠退出，不再因文件事件合并遗留多个观察器。
