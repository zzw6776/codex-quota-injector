# 更新窗口大小持久化

- 日期：2026-10-12；源码 0.1.324，macOS arm64，Node v26.7.0。
- 范围：免费回归 - 模拟模型 / macos-native 的更新契约，以及独立原生窗口保存与恢复；零下载、安装、真实模型请求或日常重启。

## 改动

原生窗口启动参数增加应用数据目录内的 `update-window-size.json` 路径，不随临时任务目录、应用版本或 Worker 可执行文件位置变化。macOS 与 Windows 在拖动结束及关闭时原子保存普通窗口的内容宽高，读取时恢复并限制到最小尺寸和当前屏幕。最大化、全屏或最小化不覆盖上次普通窗口大小。

新增大小文件的内部结构版本为 `1`，只保存 `version`、`width` 和 `height`；不保存位置。缺失、格式错误或不支持的结构版本使用默认大小，不阻塞窗口打开。
