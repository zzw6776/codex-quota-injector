## 最终行为

启动后与每 6 小时检查公开仓库 Latest Release，使用 ETag 复用未变化结果。候选包严格匹配操作系统、架构、正式版本与仓库下载路径。正式版只显示更高版本，dev 忽略版本高低比较，因此同版本或较旧的远端正式版也可测试。2026-10-12 本轮只读查询时 Latest 为 `0.1.295`，三个平台安装包均有 GitHub SHA-256 digest；这不是本地最新源码版本。

旧横栏与新侧栏额度入口的小绿点不占额度行，浮窗右下角显示绿色“有更新”。更新状态窗运行在复制到更新目录的独立 Worker 与窗口进程中，不能因 dev/正式版交接或 Codex 重启而丢失。确认前不下载；确认后依次下载、校验、等待任务结束与历史投影落盘、接管、替换和启动正式版。关闭按钮在执行期间禁用，成功/失败后保留窗口，手动关闭结束。

dev 只免除版本高低比较。下载仍验证大小和 SHA-256；macOS 验证应用版本、标识、签名、架构与资源，在应用目录暂存候选包后才允许接管。Windows 使用经摘要校验的正式 Setup 与独立 WinForms 状态窗；WSL 通过当前中继的只读历史入口核验真实 Linux 历史。历史结构异常不修复、不绕过；下载/校验异常不停止当前应用。安装失败保留现场，不备份旧安装、不回滚。

更新成功要求正式实例 PID 已变化、模式与目标版本正确、启动状态 ready、加载文件归属于本次安装、Codex/CDP 与中继就绪。窗口不能仅凭复制成功就显示整体成功。
