# 2026-11-21 macOS 开发日志窗口归属竞态修复

## 原始 CI 结果

[Build Packages #44776381891](https://github.com/zzw6776/codex-quota-injector/actions/runs/44776381891) 对应提交 `6dc13e4` / 应用 0.1.348。Ubuntu 和 Windows 的非 UI 契约测试通过；macOS arm64、Node 22.23.1 为 **763 通过、1 失败、2 跳过**。失败用例在并发打开三个开发日志观察器后等待两个旧归属退出超时；Windows、WSL、macOS 打包及 Release 任务均被门禁跳过，不是打包器执行失败。

## 原因与修复

`fs.watch` 可以合并对同一归属文件的并发原子替换事件。观察器如果在自身登记完成前收到被合并的通知，登记后又恰好读到自己的 token，就可能漏掉后续归属替换，使多个日志窗口同时存活。

修复保留文件事件的即时通知，并在每次登记后 50ms 执行一次最终归属复核；这是一次性校验，不会周期轮询。关闭观察器时同步取消尚未执行的复核。原有并发契约扩为 20 轮，同时保留“关闭后新窗口可再次登记”的检查。
