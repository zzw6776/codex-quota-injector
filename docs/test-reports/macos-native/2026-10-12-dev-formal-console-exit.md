# 正式版接管后的开发日志终端退出

- 日期：2026-10-12，America/Los_Angeles；macOS 原生 arm64，Node v26.7.0。
- 源码：应用 0.1.318；本轮未改 Widget 与 Relay 版本。
- 组件：免费回归 - 模拟模型的定向契约，以及实际残留日志进程清理；不是完整启停恢复验收。零模型请求，未构建正式安装包、安装、启动或重启注入器/Codex。

## 根因与修改

正式版的单实例接管正常退出了开发后台，但 `.command` Shell 在成功退出后继续等待 `tail -F`。旧归属协议只覆盖开发日志窗口之间的交接，未在正式接管时结束观察器。

新增 `src/macos-dev-console.mjs`，仅在 macOS 开发实例收到正式版接管请求时原子替换 `active-dev-console` 归属令牌，由原观察器通知自己的 Shell 正常退出并清理协调器与两个 follower。通知失败记录警告，继续原有后台接管；不存在观察器时不创建状态文件。

不删除归属文件：旧协调器把文件缺失当作错误，会进入失败留窗；令牌替换可复用旧协调器已有的成功交接行为。退出通知放在开发后台的接管回调，因此已安装的旧正式版本也可触发新版开发后台的退出逻辑。开发版页面更新与正常复用不发送此通知。
