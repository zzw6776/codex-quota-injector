## 变更与边界

1. 每个本机任务的当前连接就绪后，四个已知只读工具独立并发调用。跨任务最多 8 个在途探针，当前可见任务优先；重复就绪通知和切回任务复用同连接证据。
2. 逐项记录通过、检查中、异常、未确认及时间。15 秒截止仅结束前台等待，不声称工具不可用；同代且未被新检查替代的迟到响应仍可恢复。重连、配置刷新及新检查隔离旧结果。
3. 自动检查不调用全目录。完整目录为手动诊断，独立记录并读取后续分页，不能推翻四项实际调用证据。
4. “重新检查”只重试未通过项；全通过时重新验证四项。“刷新工具配置”才执行配置重载；两者没有混用。详情展示四项结果；配置刷新及重启放入“更多”。
5. 当前任务依据官方侧栏 active 标记读取，不使用后台最后活跃任务。任务切换立即清除旧展示，异步迟到读取不能覆盖新任务；远程任务不冒用本机结果。
6. 四项通过证明对应只读接口在检查时成功及基础响应结构有效，不证明所有历史内容业务语义、所有模型的工具暴露或永久可用。用量接口未提供额度数据时仍为未确认。
7. 直接 RPC 检查不发起模型回合；返回内容不写入健康记录，只保存状态、时间与脱敏错误摘要。
