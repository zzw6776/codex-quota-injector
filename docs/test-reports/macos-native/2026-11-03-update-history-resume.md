# 更新等待误判与强制重启入口

环境：2026-11-03，macOS 原生 arm64，Node 26.7.0，隔离 Chrome 156.0.8078.80。受测行为源码基于 0.1.344，提交版本为 0.1.345；仅发布版本元数据随后变化，不影响本报告的执行输入。当前更新 Worker 仍来自正式版 0.1.337，目标为当时的 0.1.344。本轮测试未安装、接管或重启日常应用。

## 原因与修复

更新开始时捕获的回合由官方 `app_update_resume` 触发。它已经有 `task_complete`，SQLite 为 completed，最终助手消息存在，历史投影字节位置等于 rollout 大小，但没有新的用户消息。旧检查器强制要求用户消息存在，因而返回 `turn-not-durable`。排查对话开始之前只读复核的 17 份近期有效 rollout 没有活动回合；开始排查后，“等待当前任务结束”还包含本次正在执行的回合，不能用这一现状否定此前误判。

修复只从 SQLite 所指的回合开始字节位置读取 `task_started`，严格绑定回合 ID、序号及归属回合 ID。仅确认触发类型为 `app_update_resume` 时，允许没有新用户消息；完成状态、终态序号、最终回复和投影追平检查继续生效。没有更改真实 rollout 或 SQLite。

更新窗口等待阶段新增“强制重启并继续更新”。页面使用跨原生宿主的独立确认框，说明可能中断任务及来不及保存；取消不发请求。确认后仅取消安全等待及其 WSL 子探测，保留下载、校验、安装和正式版启动核验。终止优先于强制操作；重复点击复用同一控制器，安装或启动错误仍保留失败状态。

## 验证

测试名称：免费回归 - 模拟模型（定向契约与临时浏览器），macOS 原生；不是完整免费回归、真实模型测试或启停恢复验收。Windows/WSL 原生未执行；WSL 子探测取消由故障注入验证。

本次主要批次合计 55/55 项通过；不把重复执行的侧栏定向复测或修复前失败相加。审查中进一步收紧自动恢复例外：只有 `first_user_item_id` 本身为空才读取并接受 `app_update_resume`，数据库声明有首条消息但对应记录丢失时仍保持阻断。此前侧栏失败来自过期断言：0.1.326 已把 36px 宿主中的额度按钮扩为 44px，并以左右各 -4px 保持居中，用于避免长金额裁切，但更新用例仍期望旧宽度 36px。修正后的断言同时核对 36px 宿主、44px 按钮、左右各 4px 外扩及更新绿点仍在按钮内，没有修改生产样式。原失败和原 HEAD 对照分别保留在 `browser.tap` 与 `baseline-browser.tap`。

浏览器核对 500×510 与 420×460 两种尺寸，确认按钮均在窗口内，取消不继续更新，状态刷新不移除确认框，确认后仅接管一次。截图位于私有目录 `force-confirm-500.png`、`force-confirm-420.png`，已目视检查最小尺寸。原生 WebKit/Windows 窗口未单独实测。

## 生效范围

此改动已在临时浏览器重新加载并确认行为。本机正式更新器为打包后的独立 Worker，不能热加载工作区源码；仍运行 0.1.337，当前旧窗口不包含新按钮。真实正式更新及强制重启未执行，工作区修复不代表该更新已完成。
