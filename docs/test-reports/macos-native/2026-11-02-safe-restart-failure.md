## 机制与重新审查

强制重启使用中止信号取消安全等待，该信号不代表整个重启已停止。错误处理现在同时检查强制重启意图：后续启动失败发布 `failed`，页面解除强制重启标记并恢复按钮。真正关闭协调器仍会清除强制意图，因此不会发布退出错误或继续重启。

新增回归覆盖强制失败后再次强制重启成功、新请求获得独立且未中止的信号、每次释放检查器，以及普通/已强制等待期间停止协调器。页面契约补充从 `restarting` 到 `failed` 时按钮解除禁用和显示错误的断言。

重新审查单请求去重、取消/关闭判定、错误发布时机、资源释放、最终状态清理及页面恢复，未发现新的常规场景问题。本次仅修改协调器错误处理，不变更页面生产实现、Relay 协议、历史门禁或计价逻辑；复用其他未受影响结果，不重跑真实模型、完整免费或启停恢复。
