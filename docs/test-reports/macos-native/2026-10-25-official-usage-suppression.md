# 屏蔽官方导航栏用量窗口

- 组件：免费回归 - 模拟模型的浏览器定向子集，macOS 原生 arm64。源码应用 `0.1.328`，Widget 从 `201` 升至 `202`；Relay 未修改。
- Node `26.7.0`，隔离浏览器 `Chrome/155.0.8059.39`，实际桌面 `26.1021.31345`。没有模型测试请求、安装、重启、提交或发布。

提交准备版本为 `0.1.329 / Widget 202`；上述版本与操作状态为原测试执行时记录。提交前仅调整发布版本和说明，页面行为输入不变，复用原浏览器 2/2 结果。已通过 package/lock 三处版本一致性检查及 CI 同源中文发布日志校验，原始记录见 `.runtime/official-usage-suppression/submit-validation.json`。

## 机制与修改

当前官方导航栏中的用量按钮带有 `aria-label="用量"`、`aria-haspopup="menu"`，点击后弹出额度来源、每周限额、额度与管理用量菜单。旧样式只覆盖原先底栏的入口结构，未覆盖这个独立按钮。

新增样式只隐藏应用导航栏中标记为“用量”或“Usage”的菜单按钮，使入口不再显示、无法获得焦点或通过指针打开窗口。React 替换节点后继续匹配。不按通用弹层结构或菜单正文隐藏其他窗口。

## 当前生效范围

日常实例仍为正式版 `0.1.328 / Widget 201`。正式实例不支持开发 Widget 热替换，因此只将同一条 CSS 规则插入当前页面的现有样式表；保留样式节点正文，避免旧运行时日常刷新将其重置。实际复核为官方入口 `display:none`、布局区域数 `0`、对应菜单未打开，头像与自定义额度入口仍可见。

当前页面已生效；页面重载或客户端重开后需加载包含 Widget 202 的新版，才能持久保留。未把当前样式补丁记为整套 Widget 202 已加载。
