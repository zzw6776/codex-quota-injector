## 修复

| 问题 | 触发条件与影响 | 处理 |
| --- | --- | --- |
| 临时迁移继承旧刷新凭据 | 导入到已有已转出或失效账号时，临时凭据错误保留旧 refresh token；切换后可能重新带入官方凭据 | temporary 状态统一不保留刷新凭据，覆盖导入、切换写回和官方同步 |
| 待重启提示被错误清除 | 配置已经保存，后续检测失败，错误处理将 pendingRestart 清零 | 操作错误只改变错误状态，保留尚未应用的配置状态 |
| Chat 推理历史串回合 | 普通 assistant 回复没有消费待处理推理，后续工具调用继承了前一回合的推理；部分 Responses 推理正文也被遗漏 | 推理绑定所属 assistant 消息，在消息边界消费；兼容 reasoning_text 与 content 正文 |
| 桌面证据混入后续回合 | 验收标记后的后续任务回合被一起解析，后来的模型或成功终态可能改变验收结果 | 将工具、模型和终态限定在标记所在回合 |
| 回滚中断被误判为已结束 | 生命周期执行器在回滚期间退出，磁盘报告已提前写成 failed，重启后可能跳过未恢复状态 | 先持久化全部待回滚项，未完成保持可恢复状态，恢复入口接受 pending/running/failed |
| Windows 恢复覆盖外部运行方式 | 测试期间有人修改运行方式字段，恢复时只检查整份文件变化而没有核对字段所有权 | 沿用切换流程的所有权条件，拒绝覆盖外部运行方式，同时保留其他配置变化 |
| 旧上游归因隐式继承 | 新桌面验收直接使用之前保留的 read_thread 归因，未核对本轮版本和读取链 | 要求归因绑定当前随机标记、运行环境及本轮版本/读取链核对记录；保留已知问题证据复用 |
| GitHub 三平台同一断言失败 | 新增 codexAppReadEmptyCompletedTurns 输出字段，但完整预期对象漏了 false | 更新预期契约；不删除断言、不跳过测试 |

回归用例覆盖上述失效机制。Windows 配置用例仍归 Windows 组件，不在 macOS 上伪装成 Windows 原生验收。
